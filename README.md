# AmbilAjah 🎓

Tools pengunduh materi kuliah dari LMS dosen (Course Untidar) menjadi file HTML mandiri yang bersih, bebas proteksi, dan siap dibuka secara offline untuk split-screen atau mencatat tugas.

## 🚀 Fitur Utama

- 🔓 **Bebas Copy & Klik Kanan:** Semua materi yang diunduh sudah dibersihkan dari skrip pelarangan klik kanan, seleksi teks, dan shortcut keyboard.
- ⚡ **Direct Download Instan:** Sekali klik tombol "Download", file `.html` langsung otomatis terunduh ke komputer/HP kamu tanpa riwayat ganda.
- 👁️ **Clean Preview:** Opsi melihat preview materi bersih sebelum mengunduh.
- 📱 **Responsif untuk Linux & Mobile:** Ukuran font, tombol, dan card disesuaikan agar nyaman dibaca di desktop Linux maupun smartphone tanpa perlu zoom manual.
- 🔙 **Navigasi Jelas:** Tombol "Kembali ke Daftar Course" di-highlight secara menonjol.
- ☕ **Halaman Dukungan (Donate Me):** Dilengkapi info tujuan aplikasi dan scan QRIS donasi.

## 📦 Menjalankan Aplikasi

```bash
cd ambilajah
npm run dev
```

Buka `http://localhost:3000` di browser.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Scraper:** Axios, Cheerio, Tough-Cookie
- **Frontend:** Vanilla HTML5, CSS3 Modern (Glassmorphism & Responsive System), Native JS
